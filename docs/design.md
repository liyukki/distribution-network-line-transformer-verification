# 设计说明

## 系统目标

基于同一馈线下配变电压与功率变化中的共同运行特征，自动校验“10 kV 馈线—配电变压器”台账归属，输出疑似错误告警、最可能的正确馈线、匹配分数与可解释证据。

## 数据生成

- 默认网络：110 kV 外部电网、110/10 kV 主变、3 条 10 kV 馈线、每条 8 台 10/0.4 kV 配变。
- 时序潮流：30 天、15 分钟分辨率、随机种子 42、平衡正序交流潮流。
- 错误台账只修改台账副本，物理网络不变；真值字段只进入评价流程。

## 算法链路

1. 预处理：时间网格对齐、短缺口插值、公共电压趋势消除、一阶差分。
2. 基线：原始电压 Pearson 相关 + 群组中心。
3. 增强：残差/差分/滚动相关、电压突变事件 Jaccard、有功功率相关，配置化加权。
4. 判定：覆盖率门禁 + 当前匹配分阈值 + 分数间隔阈值，输出保守告警或数据不足。

## 可解释证据

每个告警包含当前台账馈线、推荐馈线、候选评分、覆盖率、置信度和对应特征来源，便于人工复核。

## 工程与证据设计

- 所有运行产物由 manifest 声明 SHA-256 哈希，页面/报告先校验后解析。
- 实验清单支持严格源配置交叉核验与离线产物完整性校验。
- 默认报告可由固定命令从运行目录逐字节复现。
- 全部数据为合成数据，结论不得外推为真实电网部署效果。
